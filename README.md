# 余烬信使 · 雨城邮路 / Ember Relay

主要创作人：赤木。当前源码：**6.5.0-dual-preview**，Godot **4.7.2**。

当前同步自最新双端预览工程，包含黑发信使、三段独立刀路、雨城场景、信号站界面、菜单入口整理，以及安卓横屏触控和 Windows 键鼠操作。保留两章六区、共鸣装配、手柄、改键和存档机制。

本仓库包含完整运行脚本、美术、字体、音乐及许可，不含玩家存档、缓存、SDK、签名材料或发行程序。打开 project.godot 可运行；旧提交与既有发行版本保留。

键盘：A/D 移动，空格跳跃，J 连斩，K 射击，Shift 冲刺，Q 弹反，F 修复，R 爆发，E 交互，C 区域图，Tab 航线，Esc 暂停。手机使用横屏触控布局。

源码仍为开发预览。安卓实体设备、性能与正式发行验收尚未完成；桌面触控模拟不代表真机通过。桌面预览使用 EmberRelayDualPreview 独立存档目录。
