# 余烬信使 · 长路 / Ember Relay 4.0

两章六区的像素动作冒险，包含熔炉看守与风暴织机两位首领。

本仓库由 GitHub Actions 自动构建和发布浏览器试玩版。首次发布请在 Settings → Pages → Source 选择 GitHub Actions。构建完成后的在线试玩链接显示在 Actions 的部署结果和仓库 Deployments 中。

操作：AD 移动，空格二段跳，J 连斩，K 射击，Shift 冲刺，Q 弹反，F 修复，E 交互，Tab 地图，Esc 暂停。建议使用电脑。
